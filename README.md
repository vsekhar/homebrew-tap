# vsekhar/tap

Homebrew formulae for tools by Vivek Sekhar.

```sh
brew install vsekhar/tap/decide
```

| Formula | What it does |
|---|---|
| [`decide`](https://github.com/vsekhar/decide) | Make decisions from the command line and in scripts. |

Apple silicon Macs on macOS 15 or later get a prebuilt bottle. Elsewhere
Homebrew builds from source, which needs Swift 6.2 or later; the Xcode 26
Command Line Tools are enough. After `brew tap vsekhar/tap`, plain
`brew install decide` works too.
